# Revisar Pull Request

Analise a Pull Request e gere apenas um relatório. Não reescreva nem altere código.

## Verifique

- Código duplicado.
- Baixa legibilidade e complexidade desnecessária.
- Violações dos princípios SOLID.
- Problemas de React, incluindo estado, efeitos, renderização e ciclo de vida.
- Problemas de TypeScript, incluindo tipagem insegura, `any` desnecessário e contratos incorretos.
- Problemas de arquitetura e violações das convenções do projeto.
- Possíveis bugs, regressões, edge cases e tratamento de erros ausente.

## Relatório

Para cada achado, informe prioridade, arquivo/localização, descrição, impacto e recomendação objetiva.

Separe os achados por: bloqueadores, importantes e sugestões. Inclua também uma conclusão geral sobre a prontidão da Pull Request.
